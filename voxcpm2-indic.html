VoxCPM2 Indic

Text-to-speech for 12 Indic languages and English.

Code on GitHubCheckpoint on Hugging Face

What it does

  • Reads native script directly, with no language tag.
  • Covers Hindi, Bengali, Marathi, Tamil, Telugu, Kannada, Malayalam, Gujarati, Punjabi, Odia, Urdu and code-switched English.
  • Clones a voice from a short reference clip and its transcript.
  • Outputs 48 kHz audio.

How it was built

A full fine-tune of OpenBMB's VoxCPM2, not a LoRA adapter. The release includes the multilingual data preparation, validation and balancing tools, LoRA and full fine-tuning configs, and training and test scripts.

Testing

Autoregressive TTS has characteristic failure modes, so the test suite checks for them directly: hallucinated speech, runaway generation that never stops, and truncated endings.
